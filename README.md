# Russell Franklin -- Aerospace Engineering Portfolio

A polished engineering portfolio showcasing distributed systems, cloud infrastructure, automation, and data engineering projects.

## Tech Stack

- **Frontend**: Vanilla HTML5, CSS3, ES6 JavaScript
- **Typography**: Inter (headings/body) + JetBrains Mono (labels/code)
- **Design System**: CSS custom properties, CSS Grid, Flexbox, SVG illustrations
- **Deployed via**: GitHub Pages at [rfran059.github.io](https://rfran059.github.io)

## Structure

```
website/
  index.html       -- Hero, stats, featured work, principles
  projects.html    -- Engineering showcase with SVG diagrams
  about.html       -- Bio, skills bars, career timeline
  contact.html     -- Contact cards + form
  css/styles.css   -- Design system: colors, spacing, components
  js/main.js       -- Scroll animations, mobile menu, skill bars
```

## Design System

- **Palette**: Deep navy-black base with aerospace blue (#0ea5e9) and teal (#06b6d4) accents
- **Components**: Cards with gradient top-bar hover, stat counters, skill bars, tech badges, status badges
- **Effects**: Aurora gradient hero animation, scroll-triggered card reveals, SVG engineering diagrams
